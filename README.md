# 自主找他（astrbot_plugin_self_schedule）

> **本插件由 AI 制作。**
> 代码、配置与文档均由 AI 生成，经人工测试后发布。使用前请自行阅读代码并评估风险。

让 AstrBot 的机器人**自己决定**要不要主动来找你、以及多久之后来找你。

不是定时任务，也不是随机间隔——对话安静下来后，她（模型）会读一遍最近的聊天，
判断"现在想不想找他"，如果想，再自己定一个时间。到点由插件生成一句话直接发给你。

> 这个插件是为希望机器人更加拟人化写的：她要能拒绝、能挑时间，而不是像闹钟一样到点必响。

## 特性

- **她来决定**：想不想找你、多久之后，都由模型判断，不是配置写死的间隔
- **可以拒绝**：判断这次不打扰就什么都不做（返回 `minutes: null`）
- **自己计时自己发**：不依赖 AstrBot 的 cron 引擎（该引擎在"运行时新建的任务"上会静默失败）
- **心跳机制**：很久没聊天时，她也会隔一段时间想起你，主动判断一次
- **人格一致**：发送前会读取你配置的人格提示词，语气和人设一致
- **有节制**：最短/最长间隔、每日上限、免打扰时段三重限制
- **配置可视化**：装好后在 AstrBot 面板「插件 → 自主找他 → 配置」里直接改

## 工作流程

```
对话安静 N 秒
   ↓
读取最近对话 → 调用模型判断
   ↓
{"minutes": 90, "reason": "他刚说要去忙"}   或   {"minutes": null, "reason": "他刚睡下"}
   ↓                                              ↓
插件挂起计时                                     这次不打扰，结束
   ↓
到点 → 读人格 + 最近对话 → 生成一句话 → 直接发送
```

另外，每隔一段时间会做一次**心跳检查**：

```
距上次聊天超过 X 小时 且 没有待发计划 且 不在免打扰 且 没到每日上限
   ↓
让她判断一次（同样可以拒绝）
```

## 适用场景

希望机器人**更加拟人化**，能自己想起你、主动发起对话；平台需支持主动推送消息。

目前已在 QQ（aiocqhttp）测试通过。

建议初始配置：

```
idle_seconds             90     聊天停下 1.5 分钟后再判断
min_minutes              45     最少 45 分钟后
max_minutes             360     最长 6 小时后
max_per_day               3     一天最多三次
quiet_start               0     0~8 点不打扰
quiet_end                 8
heartbeat_check_minutes  60     每小时检查一次心跳
heartbeat_after_hours     6     6 小时没聊天才允许心跳触发
```

## 安装

### 方式一：面板安装（推荐）

1. 把本仓库打包成 zip
2. AstrBot 面板 → 插件 → 右下角 `+` → 从文件安装
3. 重启 AstrBot

### 方式二：Git 安装

面板 → 插件 → 从 Git 安装，填写本仓库地址。

### 方式三：手动

把整个目录放进 `AstrBot/data/plugins/astrbot_plugin_self_schedule/`，重启。

## 配置项

| 配置项 | 默认 | 说明 |
| --- | --- | --- |
| `enable` | true | 总开关 |
| `idle_seconds` | 90 | 对话安静多少秒后开始判断 |
| `min_minutes` | 45 | 最短多久之后（分钟） |
| `max_minutes` | 360 | 最长多久之后（分钟） |
| `max_per_day` | 3 | 每天最多主动几次 |
| `quiet_start` / `quiet_end` | 0 / 8 | 免打扰时段（小时） |
| `heartbeat_check_minutes` | 60 | 心跳检查间隔（分钟），0 关闭 |
| `heartbeat_after_hours` | 6 | 多久没聊天后允许心跳触发（小时），0 关闭 |
| `target_umos` | [] | 只对这些会话生效；心跳需要它，留空则只处理收到过消息的会话 |
| `provider_id` | "" | 用于决策的模型，留空用当前会话模型 |
| `decision_system_prompt` | 见配置 | 决策提示词，可自己调教 |

## 注意事项

- **重启会丢计划**：插件用 asyncio 计时，AstrBot 重启后未执行的计划会消失（对话或心跳后会重新判断）
- **心跳需要 `target_umos`**：冷启动后没有任何消息时，插件靠它知道该关心哪个会话
- **每天有上限**：默认 3 次，避免过度打扰
- **会花 token**：每次判断约 1,200 tokens，每次发送约 1,000 tokens，一天三次约 0.02 元（按 DeepSeek 价格估算）
- **只支持能主动发消息的平台**：目前验证的是 aiocqhttp（QQ 个人号）

## 为什么不用 cron

AstrBot 自带的定时任务在"程序运行时新建的一次性任务"上会出现**静默失败**：
任务状态标记为 completed、没有报错，但既没有调用模型，也没有发送消息。

本插件因此绕开 cron，自己用 asyncio 计时、自己调用发送接口。
